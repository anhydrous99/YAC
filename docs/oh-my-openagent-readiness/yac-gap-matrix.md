## Cross-Cutting Readiness Findings

- Current strong baselines: Plan/Build, approvals, built-in tool catalog, MCP manager internals, background sub-agents, headless one-shot runs, prompt slash commands, provider/auth config, and SQLite runtime state.
- Main parity gaps to unblock future ADRs: `MCP remove/resources/read`, `nested subagents`, `richer planning/task graph`, `headless script runner`, `web/docs/search parity`, `task/session persistence`, `Team Mode visualization`, `hooks/continuation injection`, `hashline edit semantics`, and `telemetry policy`.
- Prep-only boundary: every readiness action above is documentation, ADR, or backlog synthesis; no production code should be changed for this task.
