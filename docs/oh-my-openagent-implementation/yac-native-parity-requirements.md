# YAC-Native Parity Requirements

This is a YAC-authored requirements artifact for selective YAC-native parity. It uses the local readiness matrix as the canonical capability list and the Task 1 gate evidence as the current approval truth.

Production parity status: `PRODUCTION_PARITY_BLOCKED`. Tasks 2-3 may proceed as documentation and regression truthfulness work while Tasks 4-14 remain blocked as production implementation work until a separate approval clears license, product, privacy, and clean-room constraints.

The pinned upstream commit `e0846eb1fd221ba7d41706e71e853cb0480419ca` is recorded only as a factual behavior baseline. This artifact does not copy upstream source code, schemas, prompts, docs prose, tests, config examples, command templates, package metadata, images, or generated assets. Telemetry is excluded.

Status vocabulary: `accepted` means preserve or document existing YAC behavior; `deferred` means not selected for the first YAC-native parity target; `spike required` means no implementation may start until an approved spike resolves product, architecture, security, or UX questions; `excluded` means intentionally out of scope; `blocked` means production work is stopped by the Task 1 gate or a required approval.
